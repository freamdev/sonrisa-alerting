# Infrastructure boundary

This folder implements Identity authentication, EF Core/PostgreSQL persistence and the application selection contract. Dependencies point toward Application and Domain, never from them to concrete adapters. `Program.cs` is the composition root.

The existing `Identity/AlertsIdentityDbContext` owns Identity and the Phase 02 domain tables in one migration chain. Catalog configuration seeds fixed topic/channel reference data; `SelectionService` reads/updates independent user choices. See `docs/phase02-data.md` for schema, deletion policy and validation. Phase 04 adds `AlertDispatcher`, process-wide serialization and one startup pending-recovery scan. Events/deliveries commit together; attempts and outcomes persist with exponential delays and a three-attempt cap. Phase 05 adds `Channels/` with MailKit SMTP and Slack webhook adapters, shared plain-text formatting, configuration and a replaceable SMTP transport for tests. Recording fake senders remain test-only. Phase 06 adds `News/`: a typed HTTP source, validation/normalization, single sequential polling worker and strictly Development-only fixture route. See `docs/phase04-routing.md`, `docs/phase05-channels.md` and `docs/phase06-source-worker.md` for recovery, destinations and polling configuration/validation.
